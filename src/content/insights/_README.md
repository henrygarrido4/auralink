# insights collection (articles)

One Markdown file per article. Files starting with `_` are ignored by the loader.

```md
---
title: Article title
description: Meta description and card summary (50-160 characters).
publishedDate: 2026-02-01
topics: [seo, aeo]
tags: [small-business]
draft: true
---

Body: an educational article that answers a real question a prospective client has.
```

Write for people first. Use descriptive headings, short sections, and a direct answer near the top.
