# services collection

One Markdown file per service. Files starting with `_` are ignored by the loader.

```md
---
title: WordPress Website Development
summary: One or two plain sentences describing the service and who it is for (40-200 characters).
group: website-development
order: 20
faqs: []
draft: true
---

Body: what the service includes, the process, who it suits, and what the client receives.
```

Schema: `src/content.config.ts`. Content rules: `docs/content-strategy.md`.
