# faqs collection

One Markdown file per question. The body is the answer. Files starting with `_` are ignored.

```md
---
question: How long does a WordPress website take to build?
topics: [wordpress-development]
order: 10
draft: true
---

A direct answer in the first sentence, then the factors that change it.
```

Answers must be visible on the page where they are marked up. Do not promise outcomes.
